# 售票表單填寫輔助（Chrome 擴充功能）

一個個人自用的表單填寫輔助工具，適用於 ticketplus.com.tw。把原本需要重複手動點選的表單欄位，改成依預先設定好的內容一次填妥，並把網站處理進度顯示出來。

本專案與遠大售票（Ticket Plus）無任何隸屬或合作關係，僅為個人自用的瀏覽器輔助工具。

## 功能

1. **場次選擇** — 依關鍵字（日期／時間）選取指定場次
2. **張數填寫** — 依預先設定的票種與張數填入表單，取代重複點選
3. **條款勾選** — 勾選「我已經閱讀並同意 會員服務條款 與 隱私權政策」
4. **狀態顯示** — 把網站的處理進度與結果顯示在畫面上（見下方說明）
5. （可選）**接續下一步** — 預設關閉，避免未經確認就送出

## 安裝方式

1. 開啟 Chrome，網址列輸入 `chrome://extensions`
2. 右上角開啟「開發人員模式」
3. 點「載入未封裝項目」，選擇本資料夾
4. 完成後工具列會出現 🎫 圖示

## 使用方式

1. 點工具列的圖示，開啟設定：
   - **啟用自動模式**：勾選後，進到對應頁面會自動填寫
   - **場次關鍵字**：例如 `08-14` 或 `19:30`，留空表示選第一個可選場次
   - **票種與張數**：一行一條，格式「票種關鍵字 張數」，例如：
     ```
     全票 2
     身障票 1
     ```
     用 `*` 代表第一個票種（例：`* 2`）
   - **自動勾選條款**：預設開啟
   - **接續下一步**：預設關閉，建議自行確認後手動送出
2. 按「💾 儲存設定」
3. 進入頁面（需先登入會員）後即會依設定填寫；也可以按「▶ 在目前分頁立即執行」手動觸發
4. 右下角的浮動提示會顯示工具做了哪些動作

## 狀態顯示

網站在處理請求時，畫面上只有一個沒有文字說明的等待動畫，使用者無法分辨「仍在處理中」與「流程已結束需重新操作」。本工具把網站自己回傳的狀態顯示出來：

- **⏳ 處理中** — 回應為 `errCode 137`，網站會在倒數結束後自行重試
- **✅ 已完成，進入下一步** — 回應為 `errCode 00`
- **⛔ 流程已結束** — 回應為其他代碼，網站已停止後續處理，**需重新整理頁面**

面板同時顯示已處理次數、代碼與對應的中文說明、下次重試的倒數秒數。

### 為什麼需要這個

網站的請求處理採每輪獨立判定，不回傳順位資訊，等待時間長短與結果無關。前端在 `errCode 137` 時沒有任何文字提示，使用者只看得到轉圈動畫，無從得知現在是「還要繼續等」還是「流程已經結束、再等也不會有結果」。這個面板就是補上這個區別，避免對著已停止運作的頁面空等。

### 狀態代碼對照

對照表取自網站前端 `chunk-3225fb1b` 的 `errorHandler` 分支，中文說明取自該站自身的 i18n 語系檔。

| 代碼 | 說明 | 後續 |
|---|---|---|
| `00` | 處理完成 | 進入下一步 |
| `137` | 本輪未通過 | 依 `waitSecond` 由網站自行重試（未給則 15 秒） |
| `101` | 操作出現問題 | 流程結束 |
| `110` | 流量管控中 | 流程結束 |
| `112` / `115` / `121` | 票種售完或超過張數限制 | 流程結束 |
| `113` / `116` | 無座位／無連續座位 | 流程結束 |
| `114` | 逾時 | 流程結束 |
| `124` / `125` | 序號錯誤／已使用 | 流程結束 |
| `135` / `136` | 驗證碼錯誤／過期 | 流程結束 |
| `999` | 連線失敗（前端自行產生） | 流程結束 |

### 實作方式

`inject.js` 在頁面主環境（`world: "MAIN"`）以唯讀方式讀取網站 API 的回應內容，再透過 `postMessage` 轉給 content script 顯示。

**不修改請求、不重送請求、不改變網站原有的重試頻率或時間間隔** — 顯示的是網站本來就在做的事，只是原本沒有呈現在畫面上。

## 使用範圍與限制

- 本工具僅代替使用者在自己的瀏覽器中填寫表單欄位，所有請求皆由網站原有程式碼發出
- 不處理驗證碼、不繞過任何驗證機制、不改變請求頻率
- 僅供個人自用；請遵守該網站的服務條款與購票規範
- 送出訂單前請自行確認場次、票種、張數與金額
- 網站為 Vue SPA，本工具以「文字關鍵字＋圖示」定位畫面元件，網站改版時可能需要調整 `content.js` 的定位條件

## 檔案結構

| 檔案 | 用途 |
|---|---|
| `manifest.json` | 擴充功能設定（MV3，僅在 ticketplus.com.tw 生效） |
| `content.js` | 表單填寫邏輯與狀態面板 |
| `inject.js` | 頁面主環境的唯讀狀態讀取 |
| `popup.html` / `popup.js` | 設定介面 |
